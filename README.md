# Starlight Service

An iOS app being developed to help a plumbing business organize
service appointments, customer information, and daily jobs.

## Project Status

🚧 Active development — working prototype.

Features and interface are being refined through testing and
feedback from the intended business user.

## Features

- Home screen for viewing upcoming appointments.
- Calendar for browsing scheduled jobs.
- Appointment counts displayed on calendar dates.
- Address search suggestions powered by MapKit.
- Integration with Maps for directions to job locations.

## In Progress

- Refining appointment creation and editing.
- Improving navigation and the overall user experience.
- Expanding customer management, price book, and to-do features.

## Technologies

- Swift
- SwiftUI
- MapKit
- Xcode
- Git and GitHub

## Running the Project

1. Clone or download this repository.
2. Open `Plumbing App.xcodeproj` in Xcode on a Mac.
3. Select a compatible iPhone simulator.
4. Build and run the app.

Running on a physical iPhone requires configuring code signing
with your own Apple development team.
